通过 OpenAI 兼容的 Chat Completions API 调用大语言模型，支持流式输出、Function Calling 等功能。
POST https://model-router.edu-aliyun.com/v1/chat/completions
请求头 Headers
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
model string 必填
模型标识，可通过"模型列表"获取，如 ali-qwen2.5-72b-v1
messages array 必填
消息列表，每个元素包含 role（system/user/assistant）和 content 字段
▶ 展开子属性
stream boolean
是否使用流式输出，默认 false
stream_options object
流式输出选项，可设置 include_usage 返回 token 用量
▶ 展开子属性
temperature float
采样温度，控制输出随机性，范围 [0, 2)，默认 1.0
top_p float
核采样概率，范围 (0, 1.0]，默认 1.0。建议只设置 temperature 或 top_p 其一
top_k integer
保留候选 token 数量，≥0。设为 null 或 >100 可禁用
repetition_penalty float
重复惩罚，控制生成内容的重复度，>0
presence_penalty float
存在惩罚，范围 [-2.0, 2.0]。创意任务可增大，严谨任务可减小
response_format object
响应格式，默认 {"type": "text"}
▶ 展开子属性
max_tokens integer
最大输出 token 数，默认为模型最大值
n integer
生成回复数量，范围 1-4，默认 1。传入 tools 参数时请设为 1
enable_thinking boolean
是否开启思考模式，开启后模型先推理再回复。仅部分模型支持
seed integer
随机种子，用于结果复现
logprobs boolean
是否返回 token 对数概率，默认 false
top_logprobs integer
返回候选 token 数量，范围 [0, 5]，默认 0
stop string / array
停止序列，生成到指定字符串时停止。不可混用 token_id 和字符串
tools array
工具列表，用于 Function Calling
▶ 展开子属性
tool_choice string / object
工具选择策略：auto / none / 指定工具
parallel_tool_calls boolean
是否并行调用工具，默认 false
enable_search boolean
是否开启联网搜索，默认 false
search_options object
联网搜索策略配置
▶ 展开子属性
id string
请求唯一标识
object string
对象类型，chat.completion 或 chat.completion_chunk（流式）
created integer
创建时间戳（Unix 时间戳）
model string
使用的模型标识
choices array
生成结果数组，包含 message、finish_reason 等
▶ 展开子属性
usage object
Token 使用量（流式返回为空）
▶ 展开子属性

通过 OpenAI 兼容的 Responses API 调用大语言模型，相比 Chat Completions API 具有以下优势：1. 内置工具（联网搜索、代码解释器等）；2. 更简洁的输入格式；3. 通过 previous_response_id 简化上下文管理；4. 通过 x-dashscope-session-cache 实现便捷上下文缓存。
POST https://model-router.edu-aliyun.com/v1/responses
请求头 Headers
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
model string 必填
模型标识，如 ali-qwen2.5-72b-v1
input array 必填
输入内容数组，支持文本和图片等多模态输入
▶ 展开子属性
previous_response_id string
上一次响应的 ID，用于简化多轮对话上下文管理
tools array
工具列表，支持 web_search、code_interpreter、web_extractor 等
▶ 展开子属性
stream boolean
是否使用流式输出，默认 false
temperature float
采样温度，范围 [0, 2)，默认 1.0
max_output_tokens integer
最大输出 token 数
id string
响应唯一标识
object string
对象类型，固定为 response
created_at integer
创建时间戳（Unix 时间戳）
model string
使用的模型标识
status string
响应状态：completed / in_progress / failed
output array
模型输出内容数组，可能包含 message、tool_call 等
▶ 展开子属性
output_text string
便捷字段：将 output 中所有 output_text 拼接的纯文本结果

POST https://model-router.edu-aliyun.com/v1/messages
请求头 Headers
Authorization: Bearer <YOUR_API_KEY>

messages array 必填

▶ 展开子属性
system string
系统提示词，用于设定模型角色和行为
stream boolean

temperature number

top_p number
核采样概率，范围 (0, 1.0]
top_k integer
保留候选 token 数量
stop_sequences array

thinking object

▶ 展开子属性

id string
消息唯一标识

role string

model string

content array
